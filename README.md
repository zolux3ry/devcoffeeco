# Dev Coffee Co — open source

Coffee for people who ship. This repo is the public home for customer-visible open-source work from [Dev Coffee Co](https://www.devcoffeeco.com).

## What’s here

Starter and showcase projects tied to the shop and the tools around it. If it’s in this repo (or linked from it), it’s meant to be public.

## What’s not here

Internal store plumbing, private internal tooling, and anything that isn’t meant for the internet. Don’t expect secrets, deploy keys, or ops runbooks.

## Get started

1. Browse the repo and linked projects.
2. Open an issue if something’s broken or unclear.
3. PRs welcome — keep them small and focused.

## Shop

Roasts, blends, and shipping: [www.devcoffeeco.com](https://www.devcoffeeco.com)
